## Transcription notes

The Markdown text is a faithful transcription of the Rev6L PDF, including its
original wording, numbering and any typographical quirks (for example, rule
numbers 3.8 and 4.8 do not appear in the source document, and Annex C lists
two items labelled "c"). Any corrections should be made as tracked changes
via pull requests rather than silently during transcription.

The transcription has been verified word-by-word against the source PDF.
The only deliberate formatting differences are:

- Rule numbers are consistently written with a trailing full stop (e.g.
  "A.1." and "6.25."); the PDF punctuates these inconsistently.
- Typographic (curly) quotes are rendered as straight quotes.
- The PDF's bullet characters are rendered as Markdown list items, and the
  two footnotes are placed at the end of their respective Part files.
- The VASI diagram at rule 7.13 is an image and could not be carried over;
  see the original PDF for the illustration.
